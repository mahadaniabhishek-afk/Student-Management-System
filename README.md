# 🎓 Student Management System

A desktop-based **Student Management System** developed using Python and Tkinter. This project aims to provide a simple graphical interface for managing student information.

## 📌 Project Overview

The Student Management System is a Python-based desktop application that uses Tkinter for its graphical user interface and JSON for storing student data.

It is designed to make student information management simple and organized.

## 🚀 Technologies Used

- **Python** – Core programming language
- **Tkinter** – Graphical User Interface (GUI)
- **JSON** – Data storage

## ⚙️ Installation & Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/mahadaniabhishek-afk/Student-Management-System.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Student-Management-System
   ```

3. Make sure Python is installed on your system.

4. Run the application:

   ```bash
   python "System Management System.Py"
   ```

## 💻 Requirements

- Python 3.x
- Tkinter (usually included with Python)
- JSON support (included with Python)
